# AcenteMax – Kurulum

Sigorta acentesi yönetim programı (Windows).

## İndir

**[AcenteMax kurulum dosyasını indir](https://github.com/excelformul74-collab/acentemax-indir/releases/latest/download/AcenteMax-Kurulum.exe)**

1. Yukarıdaki bağlantıya tıklayın, kurulum dosyası iner.
2. İnen **AcenteMax-Kurulum.exe** dosyasını açın ve kurulumu tamamlayın.
3. Windows "bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır** deyin.
