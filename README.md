# MBSoft-Sigorta (Sigorta360) – Kurulum

Sigorta acentesi yönetim programı (Windows).

## İndir

**[Kurulum dosyasını indir](https://github.com/excelformul74-collab/mbsoft-sigorta360-indir/releases/latest/download/MBSoft-Sigorta360-Kurulum.exe)**

1. Yukarıdaki bağlantıya tıklayın, kurulum dosyası iner.
2. İnen **MBSoft-Sigorta360-Kurulum.exe** dosyasını açın ve kurulumu tamamlayın.
3. Windows "bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır** deyin.
